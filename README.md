# Evet Nagi – Front-End Developer Portfolio

React + Vite + Tailwind CSS + Framer Motion + Lucide (JavaScript/JSX).

    npm install
    npm run dev       # development
    npm run build     # production build in /dist

## Things to update (all in `src/data/portfolioData.js`)

- **Profile photo (pending):** add your image to `src/assets/`, import it at the top of the file and set
  `profile.photo` and `profile.photoAlt`. Currently a placeholder silhouette.
- **GitHub repo links:** set `githubUrl` on a project. The GitHub button appears only when a URL exists.
- **Live Demo links:** taken exactly from the hyperlinks embedded in the CV PDF.
- **CV file:** replace `public/Evet-Nagi-CV.pdf` (keep the file name) whenever the CV changes.
